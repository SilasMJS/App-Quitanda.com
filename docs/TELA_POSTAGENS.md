# Vitrine Social (`app/telas/postagens.tsx`)

A vitrine social permite que o vendedor poste fotos e vídeos do seu dia a dia para engajar o seu público, com o estilo Instagram.

## Funcionalidades
- **Criar Nova Postagem**: Permite carregar uma foto ou vídeo e adicionar uma legenda criativa.
- **Feed Social**: Mostra as últimas postagens já feitas pelo vendedor na vitrine.
- **Mídia Flexível**: Suporta tanto imagens quanto vídeos para uma comunicação rica.
- **Publicação na Vitrine**: Envia a postagem e limpa o formulário de forma automatizada.

## Detalhes Técnicos
- **`expo-image-picker`**: Configurado para aceitar múltiplos tipos de mídia (fotos e vídeos).
- **`TextInput` multiline**: Campo de legenda que se ajusta conforme o texto é digitado.
- **Mock Data**: Postagens de exemplo que simulam como o feed ficaria preenchido.
