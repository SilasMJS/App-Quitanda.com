# Visão Geral - Quitanda.com

O **Quitanda.com** é um aplicativo de gerenciamento de vitrines digitais, focado em dar autonomia para vendedores locais e produtores gerenciarem seus negócios de forma simples e visual.

## Objetivo
O app serve como a "central do vendedor", conectada a uma plataforma web (vitrine). Ele permite que o lojista cuide de todo o ciclo de venda, desde a exposição visual dos produtos até o controle financeiro.

## Público-Alvo
- Pequenos produtores rurais.
- Vendedores de produtos artesanais.
- Donos de quitandas e pequenos mercados.
